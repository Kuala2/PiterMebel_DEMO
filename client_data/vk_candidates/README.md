## Как сложить материалы

Для каждого поста создать отдельную папку с его номером:

```text
client_data/vk_candidates/post_229/
  photo_1.jpg
  photo_2.jpg
  post_text.txt
```

В `post_text.txt` сохранить исходную подпись поста без редактирования. Если в
публикации есть видео, достаточно сохранить обложку и указать ссылку на видео в
тексте. Категорию, название, обложку и публичное описание лучше выбрать после
сравнения всех фотографий.
