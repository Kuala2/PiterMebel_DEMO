# Фрагменты: как переносить решения, а не стиль

## Что такое фрагмент

Кроп реального скриншота (не вся страница) с подписью, что именно в нём работает. Фрагмент — направление для адаптации, не шаблон для копирования.

**Фрагмент обязан быть чистым кадром.** Cookie-баннеры, CAPTCHA, промо- и подписные модалки поверх контента запрещены во фрагментах: если overlay не закрылся при захвате — кадр бракуется скриптом (status=fail), а не «используется как есть». Кропай только из ok-кадров.

Собери 8–12 фрагментов с 4 финалистов. Обязательные поверхности: hero, навигация, listing или сетка проектов, detail, proof/process, CTA/контакт, 1–2 мобильных решения.

## Формат FRAGMENTS.md

```
## F01 — hero: слойная композиция с крупным кадром
- Источник: studio-x.ru (home, desktop-first.png)
- Тип: media
- Что видно: заголовок лежит на тёмной подложке поверх нижней трети фото; подложка — градиент от чёрного 80%
- Берём: принцип трёх слоёв (фото → подложка → текст) и выравнивание по нижней кромке
- Не берём: саму фотографию, точную палитру, шрифт
- Куда: hero главной
```

Три дисциплины:

1. **«Что видно» — только наблюдаемое.** Никаких `premium`, `editorial`, `modern` без расшифровки, что именно видно на кропе.
2. **«Берём» — свойство, а не копия.** Переносимы: ритм, плотность, масштаб, кадрирование, порядок слоёв, поведение при скролле, мобильная перекомпозиция. Не переносимы: фотографии, тексты, логотипы, точная палитра, шрифт, точная геометрия.
3. **Один источник не становится шаблоном.** Если из одного сайта взято больше половины фрагментов — результат будет «тот же сайт с другим логотипом». Разнообразь.

Тип каждого фрагмента — один из `composition`, `media`, `type`, `interaction`, `commercial`, `mobile`. В наборе 8–12 фрагментов нужны минимум: 2 `media`, 1 `commercial`, 1 `mobile`. `composition` — максимум 3, `type` — максимум 2. Это не позволяет техническим сеткам и волоскам вытеснить продукт, фотографию и сценарий продажи.

## Как делать кропы

Вырезай прямоугольники из сохранённых PNG (ImageMagick недоступен — используй canvas в headless-странице или просто пересними область через capture с узким viewport). Кроп должен быть читаемым: не уже 360px по большей стороне.

## Связь с дизайном

Каждой большой поверхности будущего сайта (hero главной, listing, detail, контакт) назначается максимум 2 фрагмента: один задаёт структуру (пространственную конструкцию), один — характер (типографика, детализация, поведение). Предпочтительно из разных источников. Дальше работает Synthesis Map основного скилла.
