# Проверка результата и цели Метрики

Счётчик проекта: **112318484**. Владелец подтвердил настройку Метрики/Вебмастера, sitemap, HTTPS и индексации. Повторно добавлять сайт или счётчик не требуется. Кабинеты в этой сессии не открывались.

Проверить цели типа «JavaScript-событие»; создать только отсутствующие:

| Идентификатор | Что измеряет |
|---|---|
| zayavka | Сервис подтвердил отправку заявки. До подключения Web3Forms не должна срабатывать |
| contact_phone | Клик по телефону; это не подтверждённый звонок |
| contact_email | Клик по email |
| contact_vk | Переход в диалог VK |
| contact_telegram | Переход в Telegram |
| contact_whatsapp | Переход в WhatsApp |
| contact_max | Переход в Max |

Существующие boost_popup_show / boost_popup_click и события всплывающего предложения сохранены. Контактные действия нельзя складывать с заявками как число уникальных лидов.

## После публикации

1. Проверить один просмотр при входе, внутренних переходах и кнопке «Назад», правильные URL/title/referer. Якорь внутри страницы не добавляет просмотр. defer: true отключает автоматический первый hit — его отправляет обработчик.
2. Проверить поступление контактных целей в отладке Метрики. Локально проверена очередь API с заблокированным внешним трафиком; получение событий кабинетом не проверено.
3. После подключения Web3Forms владельцем провести согласованную тестовую заявку: доставка → одна zayavka; ошибка/нет согласия/антиспам → ни одной. Исключить тест из бизнес-результатов.
4. Неизвестный URL и отсутствующий .js должны вернуть 404. Проверить HTTPS www.

## Базовая линия

Сравнивать 28 полных дней до фактического релиза и 28 после, Europe/Moscow. Учёт просмотров меняется: увеличение просмотров после исправления счётчика само по себе не означает рост аудитории.

- Основной результат: квалифицированные обращения и продажи, с устранением дублей.
- Метрика: органика Яндекса, посадочная, устройство, регион; заявки и контакты отдельно.
- Вебмастер: показы/клики/CTR, бренд/небренд, индексируемые URL и причины исключения. CTR = сумма кликов / сумма показов.
- Скорость: evidence/performance-*.json — локальная лаборатория; TBT не заменяет полевой INP. Нужны реальные CWV опубликованного сайта.
- Учитывать сезонность, спрос, рекламу и изменение предложения; рост после релиза не доказывает причинность.

Ответственный: владелец сайта. Проверка в день публикации, ошибок — через 7 дней, результатов — через 28 полных дней. Дата релиза не назначена, автоматическое наблюдение не настроено.
