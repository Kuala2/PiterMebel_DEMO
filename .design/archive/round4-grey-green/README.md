# Архив раунда 4 Direction — «серый + зелёный» (2026-08-23)

Отложен пользователем для независимого повторного раунда в Gemini.
**Не отклонён**: concept-1 — кандидат, с которым пользователь, возможно,
вернётся; concept-2 и concept-3 сохранены для полноты и возможного повторного
использования элементов (в рамках BRAND_MODE: EVOLVE).

## Состав

- `concept-1.html` + `shots/` + `shots-verify/` — **«Витрина»**: кухня во весь
  первый экран, шапка-плёнка только со ссылками, каптива-плашка со срезанным
  углом (мотив сгиба оригами), ряды портфолио разной ширины; зелёный — только
  действия. Лучший мобильный первый сгиб (~55–60% фото). Рекомендован
  ревьюером.
- `concept-2.html` — **«Цех»**: двухъярусная шапка с фактом-адресом, зелёная
  линейка процесса 01–04, флагман в рамке-спецификации; структурный зелёный.
- `concept-3.html` — **«Разворот»**: графитовая сервис-строка, антиквенный
  герой, фотополоса под текстом, асимметричная сетка, одна графитовая пауза со
  слоганом клиента; зелёный — ссылки и одна этикетка.
- `DIRECTION_CONTRACTS.json`, `DIRECTION_REVIEW.json`, `concept-board.png`,
  `reference-trace-board.png` — доказательная база раунда (вердикты:
  concept-1 advance, concept-2 rework→advance после правок, concept-3 advance).

## Как вернуть

Скопировать нужный `concept-N.html` обратно в `.design/style-lab/`, снять
скриншоты capture.mjs и — при выборе пользователем — извлечь токены в
`.design/DESIGN_TOKENS.md`, зафиксировав решение в `ACCEPTED.md`.

Эти три скелета (витрина-плёнка / двухъярусный цех / редакционный разворот)
считаются ИЗВЕСТНЫМИ решениями: в новом раунде их нельзя воспроизводить, но
можно вернуться к ним из архива в любой момент.
